# Dashboard route / page

## Files

- `src/routes/__root.tsx` — shell, `<Toaster />`, error + not-found screens.
- `src/routes/_dashboard.tsx` — layout + **auth guard**: `beforeLoad` → `ensureQueryData(sessionQueryOptions)`; logged out → `/login?redirect=`, non-admin → `/login?error=forbidden`. Loader prefetches topics.
- `src/routes/_dashboard/<page>.tsx` or `<page>/index.tsx` (+ `$id.tsx` detail). `src/routeTree.gen.ts` is generated by the router plugin — don't hand-edit.
- `src/configs/navigation.ts` — `NavPath` union + `NAV_GROUPS` (sidebar + breadcrumb via `findNavLocation`).
- Auth client: `src/configs/authClient.ts`; HTTP: `src/configs/axiosClient.ts` (Bearer token, 401/403 → clear token + `/login`).
- Best templates: `src/routes/_dashboard/readings/index.tsx` (server-paginated), `src/routes/_dashboard/topics.tsx` (client-side filter).

## Recipe: new page

1. Build the feature first (`feature-module` skill).
2. Create `src/routes/_dashboard/<page>.tsx`:
   ```tsx
   export const Route = createFileRoute("/_dashboard/<page>")({
     validateSearch: (s: Record<string, unknown>): PageSearch => ({
       /* hand-parse, drop defaults */
     }),
     loaderDeps: ({ search }) => ({
       params: buildXParams({ ...defaults, ...search }),
     }),
     loader: ({ context, deps }) =>
       context.queryClient.prefetchQuery(getGetXQueryOptions(deps.params)),
     component: Page,
   })
   ```
   - Loader params **must equal** the params the component passes to the hook (same defaults), otherwise the prefetch misses the cache.
   - Omit default values from the URL.
3. Search state: `const navigate = useNavigate({ from: Route.fullPath })`; update with `navigate({ search: (prev) => ({ ...prev, ...patch }), replace: true })`. Any filter change resets `page: undefined` (and closes detail ids).
4. Layout: `<PageHeader title description actions />` → toolbar → `isError ? <QueryError/> : empty ? <Empty/> : <Table/> + <Pagination/>`.
5. Navigation: add the path to `NavPath` and an item (Tabler icon, Vietnamese label) to `NAV_GROUPS`.
6. Renaming/moving a page: keep the old path as a redirect in `beforeLoad` (see `src/routes/_dashboard/question-pool/refill.tsx`, `readings/refill.tsx`).
7. Detail in URL: use a search param (`readingId`) or a `$id.tsx` route (`pool-review/$reviewId.tsx`, `tenants/$tenantId.tsx` with tabs by search param).

## Deploy notes

SPA mode (`vite.config.ts`); Vercel serves `dist/client` with rewrites to `/_shell.html`. Only env var: `VITE_API_BASE_URL` (`src/configs/env.ts`).
