# Feature module

## Folder shape

```
src/features/<domain>/
  components/   pure-ish UI (kebab-case .tsx), one component per file
  hooks/        use-<thing>.ts — wrap generated API hooks
  utils/        pure functions (validate-*.ts, mappers, parsers) + colocated *.test.ts
  constants.ts  labels, page sizes, option lists (Vietnamese labels)
  types.ts      aliases of generated model types + UI-only types
```

Shared building blocks: `features/quiz` (`ENG_LEVELS`, `QuizType`), `features/topics` (`useTopicOptions`, `useTopicNameOptions`), `features/beginner`, `features/refill`. App-wide code lives outside features: `src/components/common/*`, `src/components/ui/*` (shadcn), `src/lib/*`, `src/hooks/*`, `src/configs/*`.

There is **no hand-written service layer**: the API layer is generated by Orval into `src/apis/<tag>/<tag>.ts` + `src/apis/model/*`. Never edit `src/apis/**`; regenerate with `bun run api:gen` (see `api-contract-sync`).

## Conventions

- Imports use `@/` alias **with file extensions** (`@/features/readings/hooks/use-readings.ts`, `@/components/common/page-header.tsx`); shadcn ui imports have no extension (`@/components/ui/button`).
- Prettier: no semicolons, double quotes, width 80, Tailwind class sorting (also inside `cn`/`cva`).
- UI text is Vietnamese. Icons only from `@tabler/icons-react` (`stroke={1.5}`, `data-icon="inline-start"` inside buttons). **Never render emoji.**
- shadcn style `base-luma` on **Base UI**: composition uses the `render` prop (`<DialogTrigger render={<Button />} />`), not `asChild`.
- Minimal comments — only for non-obvious rules (e.g. why two query keys are invalidated).
- Keep components mid-sized: split table / toolbar / pagination / dialog / detail sheet into separate files.

## Query hook pattern (`hooks/use-<list>.ts`)

```ts
export function buildReadingsParams(
  input: ReadingsFilterInput
): GetAdminReadingsParams {
  /* omit empty values */
}
export function useReadings(params: GetAdminReadingsParams) {
  const query = useGetAdminReadings(params, {
    query: { placeholderData: keepPreviousData },
  })
  const data = query.data?.data // API envelope { success, data }
  return {
    items: data?.items,
    total: data?.total,
    totalPages: data?.totalPages ?? 1,
    isPending: query.isPending,
    isError: query.isError,
    error: query.error,
    refetch: query.refetch,
    isRefetching: query.isRefetching,
  }
}
```

- Always use generated query keys / options (`getGetXQueryKey`, `getGetXQueryOptions`). Only hand-written key: `["auth","session"]`.
- Export `build<X>Params` so the route loader and the component produce identical params (same cache key).

## Mutation hook pattern (`hooks/use-<action>.ts`)

```ts
const mutation = usePostEnglishTopics({ mutation: {
  onSuccess: async (res) => {
    await queryClient.invalidateQueries({ queryKey: getGetEnglishTopicsQueryKey() })
    toast.add({ type: "success", title: "Đã tạo chủ đề" })
    onSuccess?.()
  },
  onError: (error) => toast.add({ type: "error", title: "Không tạo được chủ đề", description: getApiErrorMessage(error) }),
}})
return { createTopic: (v) => mutation.mutateAsync({ data: ... }), isPending: mutation.isPending }
```

- Invalidate **every** list affected server-side (e.g. editing a reading also invalidates reading-questions — see `useInvalidateReadings` in `features/readings/hooks/use-mutate-reading.ts`).
- `toast` from `@/components/ui/toast`; errors via `getApiErrorMessage` / `isApiErrorCode(error, API_ERROR_CODE.CONFLICT)` from `@/lib/api-error.ts`.
- Mutations never retry; queries don't retry on 4xx (`src/configs/queryClient.ts`).

## Forms

- No react-hook-form / zod. Controlled `useState` values + pure `validate<X>(values) → Partial<Record<field, msg>>` + `hasErrors()` in `utils/validate-*.ts` (see `features/topics/utils/validate-topic.ts`). Re-validate on change after first submit.
- Markup: shadcn `Field`, `FieldLabel`, `FieldError errors={[msg ? { message: msg } : undefined]}`, `data-invalid`; submit button shows `<Spinner data-icon="inline-start" />` while pending.
- Map server errors to fields with `isApiErrorCode` (e.g. CONFLICT → "name already exists").

## Dialogs & views

- Short forms: `ui/dialog`. Long forms / detail views: `src/components/common/responsive-dialog.tsx` or `detail-dialog.tsx` (Drawer on mobile). Destructive confirm: `ui/alert-dialog`. `ui/sheet` is not used.
- Loading/error/empty: `TableSkeletonRows`, `QueryError`, `Empty*` (separate "no data yet" vs "no match for filter").
- Formatting: `src/lib/format.ts` (vi-VN dates, numbers, USD, per-million tokens).
